# excel-car-sales-analysis
Car sales performance analysis using Microsoft Excel

📌 Project Overview:
This project focuses on analyzing car sales data to understand sales performance by car model and identify key business trends.

🧰 Tools Used:
- Microsoft Excel
- Pivot Tables
- Charts & Filters
- Basic Data Cleaning Techniques

📊 Key Analysis Performed:
- Sales comparison by car model
- Quantity sold analysis
- Revenue contribution by different models
- Identification of top-performing car models

🎯 Objectives:
- To understand which car models generate maximum sales
- To analyze quantity sold across models
- To support data-driven business decisions

📈 Skills Demonstrated:
- Data Cleaning & Preparation
- Pivot Table Analysis
- Business Reporting using Excel
